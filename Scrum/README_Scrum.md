# Scrum — Enci-Intel Grupo 9

Esta carpeta contiene la documentación Scrum del proyecto Capstone 2026.

## Archivos

- `Product_Vision.docx`: visión, problema, objetivo, usuarios, alcance y propuesta de valor.
- `Product_Backlog.xlsx`: backlog vivo priorizado.
- `Sprint_1.docx`: registro histórico del Sprint 1.
- `Sprint_2.docx`: registro histórico del Sprint 2.
- `Sprint_3.docx`: registro histórico del Sprint 3.
- `Definition_of_Done.docx`: criterios utilizados para considerar una tarea terminada.
- `Evidencias_Scrum.docx`: documento vivo con evidencias técnicas.
- `Retrospectivas_Scrum.docx`: retrospectivas consolidadas.

## Criterio de uso

Scrum es el marco de trabajo del equipo. El tablero Kanban se utiliza únicamente como apoyo visual para representar el flujo de tareas.

Los Sprints cerrados no se sobreescriben. `Product_Backlog.xlsx` y `Evidencias_Scrum.docx` se mantienen como documentos vivos.

## Regla de transparencia

Distinguir siempre entre:
- IMPLEMENTADO
- PROBADO / VALIDADO
- PENDIENTE
- FUTURO / FUERA DE ALCANCE
